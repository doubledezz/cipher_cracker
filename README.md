# Caesar Cipher Cracker 🔓

A Python-based tool designed to decrypt and crack Caesar ciphers using custom character-shifting logic and statistical analysis.

## Features Built So Far
- **Custom ASCII Decryption Engine**: Handles custom character math for both uppercase (`A-Z`) and lowercase (`a-z`) letters using standard ASCII mapping and modulo arithmetic.
- **Punctuation & Space Preservation**: Leaves non-alphabetic characters (spaces, symbols, numbers) intact.
- **Modular Design**: Separated character shifting, string construction, and text processing.

## Usage

python3 crack.py
